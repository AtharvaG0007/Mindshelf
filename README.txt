MINDSHELF - SIMPLE E-LEARNING WEBSITE

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the E-Learningwebsite folder.
3. Double-click index.html.
4. Select Explore Courses, choose a course and start learning.

PROJECT FEATURES
- Home, About, Courses and Course Learning pages.
- Four courses: Python, C, C++ and Java.
- Only two learning levels: Beginner and Intermediate.
- Lessons include a simple explanation, important points, syntax, code example, expected output and real-life application.
- Select a topic from the sidebar or use Previous Topic and Next Topic.
- Responsive layout for phones, tablets and computers.
- Works locally after extracting the folder.

TECHNOLOGY
- HTML for page structure.
- CSS for design and responsive layout.
- JavaScript for displaying course topics and navigating lessons.

IMPORTANT
- No database, backend, login, registration, authentication or external API.
- All course content is stored in script.js.
- Keep the HTML, CSS, JavaScript and images in their existing folder structure.
